🎮 Game Overview

Sky Orb Collector is a gaze-based mobile VR game built with A-Frame. The player stands in the centre of a floating sky world and collects glowing orbs by simply looking at them. No hands, no controller — only your gaze.

Collect as many green orbs as possible before the 60-second timer runs out. In Level 2, beware red "bad orbs" that deduct points!

📦 Installation & Setup

No build tools or server required. The game runs in any modern browser.

  1. 1
    Download the file — obtain index.html from the repository or zip package.
  2. 2
    Open in a browser — double-click index.html or serve it locally with any static server (e.g., VS Code Live Server, Python's http.server).
  3. 3
    Allow motion & orientation — on iOS, go to Settings → Safari → Motion & Orientation Access and enable it. On Android, allow sensor access when prompted.
  4. 4
    VR mode — click the VR headset icon (bottom-right corner of the A-Frame scene) to enter stereoscopic split-screen. Insert your phone into a Google Cardboard viewer.

🕹 Controls

The game uses gaze-based fuse control — no hands or touch required.

ActionHow to do it
Aim at an orbMove your head / phone / mouse to point the crosshair at the orb
Collect an orbHold your gaze on the orb for ~1.5 seconds — the cursor fills and triggers automatically
Navigate menusTap buttons on-screen (desktop: mouse click)
Enter VR modeTap the 🥽 icon (bottom-right of the scene)

🌐 Levels

🌤 Level 1 – Easy

  • Bright blue sky environment
  • Slow-floating green orbs
  • Only good orbs (no penalties)
  • Good orb: +10 pts
  • 60-second timer

⛈ Level 2 – Hard

  • Dark stormy sky with lightning flashes
  • Faster-moving orbs
  • Red "bad orbs" mixed in
  • Good orb: +10 pts
  • Bad orb: −5 pts
  • 60-second timer

🏆 Scoring

  • Each green orb collected: +10 points
  • Each red (bad) orb gazed at: −5 points
  • Score cannot go below 0
  • The scoreboard is always visible in the top HUD
  • Score > 100 = Outstanding · Score > 50 = Well Done

🔧 Technical Notes

Gaze Cursor

Uses A-Frame's built-in <a-cursor fuse="true" fuse-timeout="1500"> with a raycaster targeting .collectible objects. After 1.5 s of continuous gaze, a click event fires automatically.

Textures

All textures are procedurally generated at runtime using the HTML Canvas API — no external image files needed. Radial gradients simulate a glossy sphere surface with specular highlights.

Audio

Sounds are synthesised with the Web Audio API oscillator nodes — no audio file downloads required. A looping tone sequence plays as background music.

Stereoscopic VR

A-Frame's built-in VR mode splits the view automatically when the headset icon is tapped and a VR headset (or Google Cardboard) is connected.

Single-File Architecture

The entire game — HTML, CSS, JavaScript, A-Frame scene, procedural textures, and audio — lives in a single index.html file for maximum portability.
